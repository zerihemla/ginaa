####################
####SETUP STEPS#####
####################

OPTIONAL:
Set up a virtual enviornment and activate it.

Install Requirements:
In a terminal, run the following command:
pip install -r requirements.txt

Run:
python ginaa.py

The UI is loaded directly from raw_ui_files/ginaa_gui.ui at runtime, so there
is no separate UI build step. Edit that .ui file in Qt Designer to change the UI.
